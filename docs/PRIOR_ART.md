# Prior-art and naming review

Initial read-only search: 2026-07-29. This is an orientation record, not a
trademark clearance or exhaustive academic survey.

## Naming correction

The initial scaffold used two working names that should not become the public
submission identity:

- `Highwater.ai` is already used by an unrelated quantitative-finance AI
  company.
- `Blackbox Recorder` is an existing open-source agent flight recorder with
  persistent project memory, replay, handoff context, and an MCP interface.

The proposed submission name is therefore:

**Tideproof — Admissibility Memory for High-Stakes Agents**

“Highwater Drill” is retained only as the name of the synthetic demonstration
scenario. The owner has registered `tideproof.net`, but registration is not a
trademark clearance or release approval. “Tideproof” still requires formal
trademark, package, repository, and competition-name checks before
publication.

## Relevant neighboring work

The individual ingredients are not novel by themselves:

- provenance-bearing and signed agent memory;
- evidence-gated memory and freshness rules;
- conflict-aware and bitemporal memory research;
- idempotency keys, leases, fencing tokens, and anti-replay techniques;
- portable and user-owned agent-memory protocols.

The intended contest differentiation is the combined, visible invariant:

> A retrieved memory cannot authorize an action unless its supporting evidence
> remains attributable, current, in scope, uncontested, and unspent at commit
> time.

The scarce-resource race, successor handoff without authority transfer, and
replay denial make the memory layer responsible for consequential coordination
rather than merely improving recall.
